# Projek-SDA---Shortest-Path-Djikstra

Struktur Data & Algoritma Project for Past Exam | Sains Data FMIPA UNESA

Final project for the second semester of the SDA course, implementing one of the course topics—graph algorithms—based on a research journal

the journal we used named " Implementation of the Best Route Search to Find Out the Location of
Parking Places in the E-Parking System Using the Dijkstra
Algorithm and Best First Search " 

we made modifications by implementing only the Dijkstra algorithm. This is because, following further implementation, it was found that the Dijkstra algorithm alone could represent the entire algorithm. So that were using Unesa Ketintang location for making an shorthest path between the building in there. Were using google earth to estimate the edge or the path between each building.
